# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Reporting a Vulnerability

If you discover a security issue in MCP Guard itself, please report it privately.

Do not open a public GitHub issue for vulnerabilities that could be exploited against users of the tool.

The maintainer will acknowledge reports as quickly as capacity allows and will coordinate disclosure.
